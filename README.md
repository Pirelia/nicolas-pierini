# Portfólio pessoal — Nicolas Pierini

Site pessoal de apresentação de Nicolas Rafael Pierini de Lima, estudante de Ciência da Computação na UFRGS e técnico em Desenvolvimento de Sistemas pelo SENAC Tech.

## Sobre o projeto

O site reúne informações sobre formação, habilidades, contatos e o projeto MeCalendar. O layout é responsivo, com navegação adaptada para telas pequenas e destaque visual em vermelho.

## Estrutura

```text
public_html/
├── index.html
├── README.md
├── imagens/
│   ├── logo-inf.png
│   ├── logo-ufrgs.png
│   └── Nicolas_Pierini.jpeg
├── css/
│   └── style.css
└── js/
    └── main.js
```

## Como visualizar

Não é necessário instalar dependências nem compilar o projeto. Abra `index.html` diretamente em um navegador ou use a extensão Live Server no Visual Studio Code para visualizar as alterações durante o desenvolvimento.

## Tecnologias

- HTML5 para a estrutura e o conteúdo.
- CSS3 para o visual e a adaptação a diferentes tamanhos de tela.
- JavaScript para o menu de navegação em dispositivos móveis e a atualização automática do ano no rodapé.

## Personalização

- Edite o conteúdo e os links em `index.html`.
- Ajuste as cores, o layout e os estilos responsivos em `css/style.css`.
- Altere o comportamento do menu e do ano do rodapé em `js/main.js`.
- Atualize as imagens na pasta `imagens/`, mantendo os caminhos usados em `index.html`.
